# Agents

Este proyecto se ha organizado siguiendo un flujo de agentes de IA para dividir responsabilidades y facilitar la revisión.

## Backend Agent

Diseña entidades JPA, repositorios, servicios, controladores REST, relaciones entre modelos y carga inicial de datos.

## Frontend Agent

Diseña la interfaz React, navegación, formularios CRUD, tablas, dashboard y conexión con la API.

## Testing Agent

Crea pruebas unitarias con Mockito y una prueba de integración con MockMvc.

## Review Agent

Revisa decisiones mejorables del backend para una iteración posterior.

## Documentation Agent

Genera README, documentación de ejecución y guion de demo.
